# NavidMediCare Server

Express and MongoDB backend API for the NavidMediCare doctor appointment manager.

## Live Server

Server live URL: https://your-server-live-url.com

## Features

- REST API health check for server status.
- Create, read, update, and delete appointment records.
- Save patient reviews after a verified doctor booking.
- Load reviews by doctor or patient email.
- MongoDB persistence for appointments and reviews.
- CORS configuration for the deployed client application.

## Local Development

```bash
npm install
npm run dev
```

The server runs on http://localhost:5000 by default.
